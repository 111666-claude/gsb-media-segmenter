# media-segmenter

为游戏回放和直播输出按关键帧切分的媒体片段，只用 Go 标准库。

## 口径

- 切分同时考虑解码时间、展示时间、关键帧和最小/目标/最大时长。
- 片段只能在合法随机访问点结束；超过最大时长时必须记录无法立即切分的状态。
- B 帧的展示顺序不改变解码顺序，末尾不完整片段也要正确收尾。
- 返回 `work`，处理量随输入帧数增长，不重复重算已完成片段。

## 不变量

- 片段编号连续，片段字节总量等于输入帧字节总量。
- 每个独立片段从关键帧开始。
- 输出解码时间单调，展示时间可以因重排而不同。

## 输出契约

CLI 输出 JSON：`segments` 包含 `number`、`start_dts`、`end_dts`、`duration_ms`、`bytes`、`independent`；另有 `work`。
